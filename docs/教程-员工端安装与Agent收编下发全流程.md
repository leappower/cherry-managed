# CherryStudio 企业受管版 · 完整使用教程（从零到一）

> 适用：管理员 / 新员工 | 2026-08-24
> 这套系统就两样东西：**员工端（CherryStudio 安装包）+ 服务器（管理后台）**。
> 员工端负责"用"，服务器负责"发"。下面的教程一步步照做即可。

---

## 第一部分：员工端 —— 在哪下载、怎么安装

### 1.1 下载员工端安装包

**安装包**：`Cherry-Studio-2.0.7-x64-setup.exe`（109MB，Windows）

下载方式（任选）：
- **公司共享网盘**（推荐，内网快）：放在网盘共享目录 `CherryStudio-员工端/`
- **GitHub 下载**：https://github.com/leappower/cherry-studio-managed/releases （找 `Cherry-Studio-2.0.7-x64-setup.exe`）
- U盘拷贝

### 1.2 安装（员工操作，约 2 分钟）

1. 双击 `Cherry-Studio-2.0.7-x64-setup.exe`
2. 一路「下一步」，装到默认目录（C 盘或 D 盘均可）
3. 安装器自动完成三件事，**无需手动操作**：
   - 装好 CherryStudio 本体
   - 放入内置 sidecar（`安装目录\resources\sidecar\sidecar.exe`）
   - 注册 Windows 服务 `CherrySidecar`（开机自启 + 崩溃自动重启）

### 1.3 首次启动：填服务器地址（这一步必做）

1. 桌面打开「Cherry Studio」
2. **第一次启动会自动弹出「配置 CherryStudio 服务端」窗口**
3. 填服务器地址：**`192.168.3.181`**（端口默认 2334 不用改）
   - 窗口里有「扫描局域网」按钮，会自动找出服务器，点一下也行
4. 点「保存」→ 员工端就自动连上服务器了

> 判断连上没有：员工机 Windows「服务」里有 `CherrySidecar`（运行中）；
> 服务器后台「设备」tab 能看到这台机器 online=1。

### 1.4 员工怎么用下发的 Agent

- 服务器推过来的 Agent **自动出现**在 CherryStudio 里
- 如果刚推的没看到 → **重启一次 CherryStudio**
- 员工全程不需要任何手动配置

### 1.5 （可选）解锁「分享 Agent」能力：升级 sidecar

2.0.7 自带的 sidecar 能**收包**，但**还不能"被服务器收编"**（把自己调试的 Agent 给服务器）。
想让自己调试的 Agent 能分享给同事，跑一次升级（1 分钟）：

1. 下载 sidecar 升级包：https://github.com/leappower/cherry-managed/releases/tag/sidecar-20260824-collect
2. 取 `sidecar.exe` + `upgrade_sidecar.bat` 两个文件放到一起
3. 右键 `upgrade_sidecar.bat` → **以管理员身份运行**
4. 完成。这台电脑之后既能收包、也能被服务器收编。

> 不做这步的机器：只能收包，不能分享自己调好的 Agent。要不要做由你定。

## 第二部分：管理员 —— 怎么把 Agent 上传到服务器

服务器管理后台：**`http://192.168.3.181:2334/admin/`**
登录：`admin` / `admin123`

### 2.1 三种方式把 Agent 变成"配置包"（存到服务器）

| 方式 | 在哪个 tab | 怎么操作 | 适合 |
|------|-----------|---------|------|
| **A. 从设备导入** | 「包配置」 | 顶部「📥 从设备导入」→ 选设备(员工机) → 列出它上面的 Agent → 选一个 →「导入为配置包」 | **员工机上调好的 Agent 收编进服务器** |
| **B. 从 .json 导入** | 「包配置」 | 顶部「📄 从 .json 包文件导入」→ 选 .json 文件 → 上传 | 别处导出的 Agent 包文件 |
| **C. 手工新建** | 「包配置」 | 右侧表单填名称/版本/model/提示词 → 创建 | 从零做一个包 |

> ⚠️ 方式 A 的要求：目标员工机 sidecar 已升级（见 1.5），否则服务器列不到它的 Agent。

### 2.2 把服务器上的包导出成 .json（可搬运/备份）

「包配置」tab → 左侧列表 → 每行最右边「⬇」按钮 → 下载 `<名字>.agent.json`。

## 第三部分：管理员 —— 怎么把 Agent 下发给员工

### 3.1 推送

1. 进「**推送Agent**」tab
2. 选择要推的**配置包**（2.1 建好的）
3. 选**目标设备**（单个员工 / 分组）
4. 点「推送」
5. 员工端自动收到 → 落盘 → 重启 CherryStudio 即用

### 3.2 确认下发成功

- 进「**派发日志**」tab，看这条推送的**状态**：`success` = 成功
- 涉及多台设备会逐台显示

## 五、完整流程示例（一次真实操作）

**场景**：员工 A 在 40 号机调好了一个 Agent「客服助手」，管理员想发给全公司。

1. 40 机 sidecar 已升级（1.5）
2. 管理员进「包配置 → 从设备导入」→ 选 40 号机 → 列出 Agent → 选「商业助手」→ 导入
   → 服务器产生配置包「商业助手 v1.0.0」
3. 管理员进「推送Agent」→ 选「商业助手」→ 选目标（全部员工 / 指定）→ 推送
4. 员工端收到 → 重启 CherryStudio → 出现「商业助手」，直接可用
5. 员工 B 觉得好用 → B 的机器也升级 sidecar → 也能把自己 Agent 共享出来，循环起来

## 六、常见问题

| 问题 | 原因 / 解决 |
|-----|------------|
| 员工机连不上服务器 | 填写服务器 IP 了吗？同网段吗？Windows 服务里 CherrySidecar 是运行中吗？ |
| 推了 Agent 员工看不到 | 重启一次 CherryStudio |
| 「从设备导入」看不到某台机器 | 那台 sidecar 没升级（1.5）；或设备离线 |
| 「从设备导入」某台机器 Agent 列表空 | 该机 CherryStudio 里确实没有 Agent，或 sidecar 旧 |
| 员工重装 / 换电脑 | 重装 1.2 → 1.3，服务器重新推送即可 |
