## 生图规则（重要）

用户要求生成图片时，遵循以下流程：

**第一步 — 确认模型选择：**
先使用 --confirm 模式展示可用模型清单给用户：
```bash
python3 mll-client.py generate --prompt "用户的描述" --confirm -o output.png
```

**第二步 — 用户确认模型后：**
用指定的模型执行生图，只调一次命令，不要额外分析，不要重试：
```bash
python3 mll-client.py generate --prompt "用户的描述" --model 用户选的模型ID -o output.png
```

## 约束

- 只调一次命令
- 不额外分析生图结果
- 不重试
- 如果用户没指定模型，用 --confirm 展示清单让用户选
- 有环境变量 MLL_KUAI_KEY 时自动使用
- 没有 Key 时提醒用户配置
